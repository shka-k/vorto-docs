Vorto is a Rust-based modal terminal editor that bundles an LSP client, tree-sitter syntax highlighting, and GitHub Copilot support (through the Copilot LSP). Grammars install on demand, and the entire configuration lives in a single TOML file — no plugin manager, no init.lua, no package.json.

## Get up and running

<Steps>
  <Step title="Install Vorto">
    Install from crates.io with a single command:
    ```bash
    cargo install vorto
    ```
  </Step>
  <Step title="Open a file or directory">
    Launch Vorto with a file path or open a directory to start with the fuzzy file picker:
    ```bash
    vorto myfile.rs
    # or open a project directory
    vorto .
    ```
  </Step>
  <Step title="Install language grammars">
    Add syntax highlighting for your languages on demand:
    ```bash
    vorto grammar install rust python typescript
    ```
  </Step>
  <Step title="Configure your editor">
    Create `~/.config/vorto/config.toml` to set keybindings, themes, and language options.
  </Step>
</Steps>
