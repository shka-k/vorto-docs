## The editor should be done

**If your current modal-editor config mostly exists to bolt on LSP, tree-sitter, fuzzy finding, and Copilot, Vorto replaces that whole stack with one binary.** No plugin manager, no per-plugin upgrade ritual, no morning where the LSP client and the tree-sitter runtime disagree about a breaking change. The editor either runs or it doesn't, and it updates atomically with `cargo install vorto`. And in an AI-assisted workflow — where the editor is one tool alongside a coding agent, a terminal, and a review loop — the hours that plugin upkeep used to justify are better spent shipping.

For the philosophy behind these choices, see [Why Vorto](/why-vorto).

## Install

Vorto is a single static binary. Install it from [crates.io](https://crates.io/crates/vorto) with Cargo or with [mise](https://mise.jdx.dev):

<CodeGroup>

```bash Cargo
cargo install vorto
```

```bash mise
mise use github:vorto-editor/vorto
```

</CodeGroup>

Then confirm the binary is on your `PATH`:

```bash
vorto --version
```

That's enough to open your first file. For building from source and other options, see [Installation](/installation); to start editing, head to the [Quick start](/quickstart).

## Highlights

- **Batteries included.** The LSP client, tree-sitter engine, fuzzy finder, file explorer, and Copilot integration all ship in the binary — no plugin manager, no init script, no `package.json`. Each language's grammar and LSP server install once with a single command, and Vorto wires them up automatically.
- **Vim commands, lower learning cost.** Vorto follows Vim's modal model, and surfaces [command hints inline](/editing/hints) so you don't have to keep the full keymap in your head. Pick it up faster; come back to it after a month without losing the muscle memory.
- **One config file.** Keybindings, themes, indentation, and per-language settings all live in a single TOML file. Nothing to bootstrap, nothing to migrate.

## Core concepts

**Modal editing.** Five modes (Normal, Insert, Visual, Visual Line, Visual Block) plus a `:` command prompt. The status bar always shows the active mode. See [Editing modes](/editing/modes).

**Language support.** Tree-sitter grammars install on demand via `vorto grammar install`. 37 languages ship with built-in recipes. See [Supported languages](/languages/supported-languages).

**LSP client.** Diagnostics, completions, hover, code actions, and goto definition out of the box. Servers spawn lazily when you open a file. See [LSP overview](/lsp/overview).

**Configuration.** A single TOML file at `~/.config/vorto/config.toml` controls editor settings, keymaps, languages, and LSP servers. See [Configuration overview](/configuration/overview).
