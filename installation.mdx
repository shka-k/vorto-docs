---
title: "Install Vorto with mise, Cargo, or from source"
description: "Install Vorto with mise, from crates.io with Cargo, or build from source with Make or Cargo. Verify the binary before opening your first file."
---

Vorto is distributed as a single static binary. You can install it with [mise](https://mise.jdx.dev), from [crates.io](https://crates.io/crates/vorto) using Cargo, or build it yourself from the source repository. The Cargo and source paths require a Rust toolchain that supports edition 2024.

<Note>
  A C compiler (such as `gcc` or `clang`) is required when building tree-sitter grammars after installation. The editor itself compiles and runs without one, but `vorto grammar install` will fail without it.
</Note>

## Install with mise

[mise](https://mise.jdx.dev) can install Vorto directly from the GitHub repository and pin the version per project:

```bash
mise use github:vorto-editor/vorto
```

This installs the latest release and adds Vorto to the active mise environment so the `vorto` binary is on your `PATH`. Run the command inside a project directory to scope the version to that project, or pass `-g` to install it globally.

## Install from crates.io

To install directly from crates.io with Cargo:

```bash
cargo install vorto
```

Cargo downloads, compiles, and places the `vorto` binary in `~/.cargo/bin`. Make sure that directory is on your `PATH`.

## Install from source

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/vorto-editor/vorto.git
    cd vorto
    ```
  </Step>
  <Step title="Build and install">
    Choose one of the two methods below:

    <CodeGroup>

    ```bash Make install
    make install
    ```

    ```bash Cargo build
    cargo build --release
    ```

    </CodeGroup>

    `make install` places the binary at `~/.local/bin/vorto`. Make sure `~/.local/bin` is on your `PATH`.

    `cargo build --release` produces the binary at `target/release/vorto`. Copy it to a directory on your `PATH` manually.
  </Step>
</Steps>

## Verify the installation

Run the following command to confirm Vorto is installed and accessible:

```bash
vorto --version
```

You should see output like `vorto 0.11.3`. If the command is not found, check that the install directory is included in your `PATH`.

## Next steps

Vorto does not bundle tree-sitter grammars or language servers, so two more steps turn on the full experience for a language:

- **Syntax highlighting** — install the tree-sitter grammar for the language you use first, e.g. `vorto grammar install rust`. See [Install and manage grammars](/languages/grammars) for the build prerequisites.
- **LSP features** — install the matching language server and make sure its binary is on your `PATH`. See [Set up LSP support](/lsp/setup).

<Tip>
  Install the grammar before you open your first file so syntax highlighting is on from the start.
</Tip>
