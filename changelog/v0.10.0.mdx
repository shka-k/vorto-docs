Released **May 21, 2026**.

## New features

- **File tree explorer.** Press `<space>e` to open a tree-style file explorer for the current workspace. See [Commands and pickers](/editing/commands).
- **Published to crates.io.** Tagged releases are now published automatically, so you can `cargo install vorto`. See [Installation](/installation).
