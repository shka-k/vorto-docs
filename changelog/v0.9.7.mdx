Released **May 19, 2026**.

## New features

- **Bracketed paste in Normal mode.** Paste from your terminal directly in Normal mode without entering Insert first.

## Updates

- **Smarter LSP workspace root.** The LSP client walks up from the opened file to detect the workspace root, so servers attach correctly when you open a file from a subdirectory.
