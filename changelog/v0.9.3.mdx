Released **May 18, 2026**.

## New features

- **`:bca` drops all buffers.** Closes every open buffer in one command — useful when you want to start fresh without quitting.
- **`:bc` is now force-close.** The existing `:bc` becomes a force-close variant; use the standard prompt flow if you want the unsaved-changes warning.
